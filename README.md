# COSMOS WATCH — Android / Flutter starter

## Что уже реализовано
- Единая нижняя навигация: Главная, Радар, Объекты, События, Настройки.
- Серебристый полупрозрачный Liquid Glass стиль.
- Реальный запрос координат МКС к `api.wheretheiss.at` с обновлением каждые 15 секунд.
- Ссылка на публичный канал NASA для открытия трансляции.
- Базовый радарный экран и каркас остальных вкладок.

## Запуск
1. Установить Flutter SDK и Android Studio.
2. В распакованной папке выполнить:
   - `flutter create . --platforms=android`
   - `flutter pub get`
   - `flutter run`
3. Для APK: `flutter build apk --release`

## Важно
Это исходный стартовый проект, не готовый APK. Радар пока схематический; реальные TLE/SGP4-расчёты, каталог малых тел, календарь событий, AR с камерой, загрузка языковых пакетов и полноценное воспроизведение видеопотока внутри приложения требуют следующих этапов. NASA/YouTube может менять адреса трансляций и доступность.

## Сборка APK без компьютера (через GitHub Actions)
1. Создайте репозиторий на GitHub в браузере телефона и загрузите туда содержимое архива.
2. Откройте вкладку **Actions** и разрешите запуск workflows, если GitHub попросит.
3. Выберите **Build Android APK** → **Run workflow**.
4. После завершения откройте запуск workflow, внизу скачайте artifact `cosmos-watch-android`.
5. Распакуйте artifact ZIP и установите `app-release.apk` на телефон. Android может попросить разрешить установку из этого источника.

Сборка выполняется на серверах GitHub; Flutter SDK и Android SDK на телефон устанавливать не требуется.
